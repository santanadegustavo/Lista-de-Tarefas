# Lista de Tarefas

Boas-vindas ao meu projeto de Lista de Tarefas! Criei essa aplicação web para colocar em prática a lógica de programação e a manipulação de elementos na tela (o famoso DOM). É uma ferramenta simples e funcional para ajudar na organização do dia a dia.

Quer ver como ficou? [Clique aqui para acessar o site](https://santanadegustavo.github.io/Lista-de-Tarefas/)

## O que o site faz?

A ideia foi criar um gerenciador de tarefas direto ao ponto, onde a interação acontece em tempo real:

* Você digita uma nova atividade e a adiciona rapidamente à lista.
* Pode marcar as tarefas como concluídas (para dar aquela sensação boa de dever cumprido).
* Pode excluir tarefas que não são mais necessárias ou que foram digitadas por engano.
* A interface reage instantaneamente aos seus comandos, sem precisar recarregar a página.

## Como foi construído?

O projeto foi desenvolvido focando em fortalecer a base do front-end, unindo o visual com o comportamento dinâmico:

* **HTML5:** Para estruturar os campos de texto, os botões e a base onde as tarefas aparecem.
* **CSS3:** Responsável por deixar a aplicação com um visual limpo, agradável e fácil de usar em diferentes tamanhos de tela.
* **JavaScript:** O cérebro do projeto! Aqui apliquei conceitos essenciais como laços de repetição, manipulação de arrays e a interação direta com o DOM para capturar o texto digitado, criar novos itens na tela e excluí-los quando necessário.

## Quer testar no seu computador?

Se quiser baixar o código e ver como fiz a lógica do JavaScript funcionar por dentro, é super simples:

1. Faça o clone deste repositório rodando o comando: `git clone https://github.com/santanadegustavo/Lista-de-Tarefas.git`
2. Abra a pasta do projeto no seu editor de código.
3. Dê dois cliques no arquivo `index.html` para abrir diretamente no seu navegador.

Feito com dedicação para aprender e dominar cada vez mais o desenvolvimento web front-end.
